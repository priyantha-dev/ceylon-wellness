# CEYLON WELLNESS — V10 Real Business Platform

GitHub Pages-ready static build.

## Before launch
1. In `script.js`, replace `CONFIG.email` with the real enquiry email.
2. Add the real WhatsApp number to `CONFIG.whatsapp` in international digits only, e.g. `9477XXXXXXX`.
3. Add a real GA4 Measurement ID to `CONFIG.analyticsId` only after your privacy/consent setup is final.
4. Replace remote/reference photography with owned or licensed high-resolution production assets and record source/licence details.
5. Confirm provider relationships. Sayora is shown as a real public wellness centre with partnership status explicitly marked as pending; it is not presented as a Ceylon Wellness partner.
6. Select and contract the actual Sri Lanka travel operator before presenting any operator as a booking partner.
7. Replace the starter privacy notice with legal text prepared for the actual data controller, jurisdictions, processors, retention periods and contact details.
8. For true online payment/booking, connect a proper booking/PSP/backend service. This static build intentionally does not pretend to take payment or confirm availability.

## Current business flow
Wellness need → personalised draft → provider/logistics confirmation → human review → quotation → booking handoff.
